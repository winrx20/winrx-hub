# WinRX Hub dashboard

Run the live dashboard from the hub root:

```bash
bash install.sh
bash bootstrap.sh
export PATH="$PWD/bin:$PATH"
winrx health
winrx dashboard
```

Open http://127.0.0.1:8787 in a browser. The dashboard is intentionally static and safe to host anywhere; repository/process health is displayed from `dashboard/data.json` when generated by a local health exporter.

## Process management

```bash
winrx start 9router
winrx status
winrx logs 9router
winrx restart 9router
winrx stop 9router
winrx stop all
```

Processes run in the background with PID files under `.runtime/pids` and logs under `.runtime/logs`. The `.runtime` directory should not be committed.
